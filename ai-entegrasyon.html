AI ile Entegrasyon

BBK API entegrasyonunu AI aracınızla hızlandırın.

Codex, Claude, Cursor veya ChatGPT'ye BBK API dokümanını vererek özel ERP, panel veya e-ticaret akışınız için entegrasyon kodunu adım adım hazırlatın.

Başlangıç adımları API dokümanı
AI aracına kurdurabileceğiniz akışlar
  • Fiyat hesaplama
  • Sipariş oluşturma
  • Takip ve kurye konumu
  • Webhook durum bildirimi
API key kullanın · şifre paylaşmayın
Başlangıç

AI aracınızla entegrasyonu 4 adımda başlatın.

Bu akış, teknik ekibi olan müşterilerin BBK API entegrasyonunu daha hızlı planlamasına ve kodlamasına yardımcı olur.

1

API dokümanını AI aracına bağlayın

Codex, Claude, Cursor veya ChatGPT içinde BBK API doküman linkini paylaşın. AI aracından önce endpointleri okumasını, sonra entegrasyon planı çıkarmasını isteyin.

Prompt
BBK API dokümanını incele:
https://iremarslaner-sudo.github.io/banabikurye-api-docs/

Önce endpointleri ve gerekli alanları özetle.
Sonra benim sistemim için entegrasyon planı çıkar.
2

Kendi sisteminizi tarif edin

ERP, panel veya özel yazılımınızın dilini, framework'ünü, sipariş tablonuzu ve webhook alabileceğiniz URL'yi belirtin. Ne kadar net tarif ederseniz AI aracı o kadar doğru kod üretir.

  • Kullandığınız teknoloji: Node.js, PHP, Python, Laravel, .NET vb.
  • Sipariş, müşteri ve adres alanlarınız
  • Webhook durumlarının hangi alanı güncelleyeceği
3

Hazır prompt ile entegrasyon kodunu üretin

Aşağıdaki prompt'u kendi teknoloji bilginizle güncelleyip AI aracınıza verin. API anahtarınızı prompt'a yazmayın; ortam değişkeni olarak kullanılmasını isteyin.

Kopyalanabilir prompt
BBK API ile özel ERP entegrasyonu kurmak istiyorum.
Teknoloji: [Node.js / PHP / Python / Laravel / .NET]
Sipariş modelim: [alanları buraya yaz]
Webhook URL'im: [örnek: https://example.com/bbk/webhook]

Lütfen şu akışı kodla:
1. Teslimat fiyatı hesaplama
2. Sipariş oluşturma
3. Sipariş takip sorgusu
4. Webhook durum bildirimi alma

Kurallar:
- API anahtarını ortam değişkeninden oku.
- Hataları kullanıcıya anlaşılır döndür.
- Önce dosya planını çıkar, sonra kodu yaz.
- Test örnekleri ve örnek payload ekle.

Sandbox/test akışıyla doğrulayın

Kod üretildikten sonra örnek payloadlarla fiyat hesaplama, sipariş oluşturma ve webhook durum güncellemesini test edin. Canlı API anahtarını sadece güvenli ortam değişkeninde tutun.

Sonraki adım

BBK MCP Server

Bir sonraki aşamada BBK için resmi bir MCP server hazırlanabilir. Böylece Claude, Codex veya Cursor; fiyat hesaplama, sipariş oluşturma, takip ve webhook akışlarını doğrudan araç olarak çağırabilir.

AI aracınıza verebileceğiniz hazır kaynaklar.

Örnek payloadlar, ilk test siparişi akışı ve hata çözüm tablosu ile AI aracından daha net kod isteyebilirsiniz.

Güvenlik önerisi

API anahtarınızı veya canlı müşteri verilerinizi AI aracına doğrudan yazmayın. Anahtarı `.env` veya sunucu ortam değişkeninde saklayın; AI'dan kodu bu değişkenden okuyacak şekilde üretmesini isteyin.
