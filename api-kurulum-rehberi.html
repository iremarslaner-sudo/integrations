Checklist

Başlamadan önce bu bilgileri hazırlayın.

Bu liste hazırsa geliştiriciniz veya AI aracınız entegrasyonu daha az soru ile tamamlayabilir.

01

API erişimi

API key/token, test bilgileri ve yetkili hesap hazır olmalı. Anahtarı kod içine yazmayın; ortam değişkeni kullanın.

02

Sipariş alanları

Müşteri adı, telefon, teslimat adresi, ürün/tutar, ödeme tipi ve teslimat notu alanlarını eşleştirin.

03

Çıkış adresi

Depo/mağaza çıkış adresi, çalışma saatleri ve kurye notu gibi operasyonel bilgileri netleştirin.

04

Webhook URL

BBK durum bildirimlerini alacak güvenli bir URL hazırlayın ve ERP'de hangi alanın güncelleneceğini belirleyin.

İlk Test

İlk test siparişini sırayla oluşturun.

Bu akış başarılıysa entegrasyonun ana omurgası çalışıyor demektir.

1

Fiyat hesaplayın

Çıkış ve teslimat adresiyle fiyat hesaplama isteği gönderin. Cevapta servis verilebiliyor mu, fiyat ve tahmini süre dönüyor mu kontrol edin.

2

Test siparişi oluşturun

ERP sipariş ID'nizi `external_order_id` gibi tekil bir alanla gönderin. Böylece BBK siparişi ile ERP kaydını sonradan eşleştirebilirsiniz.

3

Durumu sorgulayın

Oluşan siparişin BBK sipariş ID'si veya kendi ERP sipariş ID'niz ile takip sorgusu yapın.

Webhook'u doğrulayın

Durum bildirimi geldiğinde ERP tarafında doğru siparişin doğru statüye geçtiğini kontrol edin. Test için geçici bir webhook URL'i kullanabilirsiniz.

Hata Çözümleri

En sık görülen sorunlar ve kontrol noktaları.

Bu tablo destek ekibine ihtiyaç duymadan ilk kontrolleri yapmanıza yardımcı olur.

SorunKontrol edinÇözüm
Yetkisiz istekAPI key/token eksik veya hatalı olabilir.Ortam değişkenini, header formatını ve aktif hesabı kontrol edin.
Adres hatasıİl, ilçe, açık adres veya koordinat eksik olabilir.Adres alanlarını zorunlu alanlarla eşleştirin ve Türkçe karakter/format sorunlarını test edin.
Servis dışı bölgeÇıkış veya teslimat adresi kapsama dışında olabilir.Fiyat hesaplama endpoint'iyle önce servis uygunluğunu kontrol edin.
Webhook gelmiyorURL erişilebilir değil, HTTPS yok veya endpoint 2xx dönmüyor olabilir.Webhook URL'inizi dışarıdan erişilebilir yapın ve gelen istekte hızlıca 200 yanıt dönün.
Sipariş eşleşmiyorERP sipariş ID'si BBK siparişiyle saklanmamış olabilir.Her siparişte tekil `external_order_id` gönderin ve cevaptaki BBK ID'sini kaydedin.

Destek alırken paylaşmanız gerekenler

Endpoint adı, request zamanı, request ID varsa request ID, örnek payload, dönen hata mesajı ve beklenen sonucu birlikte gönderin. API key veya canlı müşteri verisi paylaşmayın.
